   —laOra o Activala— aunque el proyecto sea el mismo. Los pasos para

   las tildes (`ó` → `√≥`) y los correos salen ilegibles. Pasó el 06/08. Se
   despliega por CLI, que sube el fichero tal cual está en disco:

   ```
   supabase functions deploy enviar-correo-auth \
     --project-ref uikanfvigunjhzibnhxf --no-verify-jwt
   ```

   así que se copia ahí desde `.supabase/` en una carpeta aparte y se despliega
   con `--workdir`. La fuente sigue siendo la de este repo.
